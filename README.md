# LWT：解释型通用脚本语言大作业

本仓库用于实现 LWT 语言、解释器、黑盒测试、性能对比、开发指南和 Agent 编写的应用。**S1 语言规范与 S2 CLI、错误模型和词法分析均已审查通过并合入 `main`**。S2 已将重复 `record` 声明字段定为解析期错误，并明确注释中的 U+FEFF 会被忽略。目前尚无 parser 或 runtime；词法有效的非空脚本会得到临时 `Incomplete` 诊断（退出码 1），这不是最终语言行为。

## 阅读入口

1. [作业原文](大作业内容.md)：教师要求与评分项。
2. [总体方案与复检](LWT大作业总体方案与复检.md)：目标、取舍、阶段门槛。
3. [详细实施规划](详细实施规划.md)：语义草案、文件结构、任务和验收方法。
4. [阶段执行与审查路线图](阶段执行与审查路线图.md)：两个聊天窗口的接力方式、S0–S12 阶段门槛和报告格式。
5. [正式语言规范](docs/language-spec.md)：S1 审查通过的 LWT 语法和语义，S2 已在本阶段分支正文补入两项澄清。
6. [project.md](project.md)：当前状态、已定决策和下一步，供编程 Agent 复用。

运行 S2 阶段词法与 CLI 测试：

```powershell
python -m unittest discover -s tests -v
```

当前仅空源文件（包括仅空白或注释）可由 `python -m lwt <source-path>` 成功返回；词法有效的非空文件显示临时阶段未完成诊断并返回 1，词法错误返回 2，CLI/源文件错误返回 4。该临时行为预计在 S4 解释执行能力具备后移除。后续阶段再补充完整解释器、一键黑盒测试、性能和应用命令。
