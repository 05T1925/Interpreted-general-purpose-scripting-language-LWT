# S48 现场人工 GUI A–E 验收包

> **必须由用户本人在无遮挡桌面执行**。执行窗口只提供工具、步骤与登记脚本，不代操作、不自动判 PASS。
> 沿用 [S21 验收报告](s21-gui-acceptance.md) 的停止规则：一旦出现窗口遮挡或输入无法归因，立即停止并记录，不绕过、不反复点击。

## 0. 准备

```bash
cd <仓库根>
python -m lwt --version          # 期望 lwt 0.3.0
python -c "import tkinter; print(tkinter.TkVersion)"
```

- 关闭其他窗口，只保留目标应用；确认任务栏无弹窗、无输入法候选框遮挡。
- 截图保存到 `evidence/gui/`，命名规范：`<项号>-<步骤>-<YYYYMMDDTHHMMSS>.png`（例：`A-2-predict-20261110T120501.png`）。录屏用 `.mp4`，同规则。
- 完成后运行登记脚本：

```bash
python tools/register_gui_evidence.py
python tools/run_acceptance_selfcheck.py --skip-heavy   # 查看 gui_evidence 步骤
```

登记脚本只计算 SHA-256、时间戳与缺项，**不会**把文件存在当成通过；最终 PASS 必须由你本人在登记表上确认。

## A. 语义实验室（约 6 分钟）

启动：`python -m app.language_lab`

| 步骤 | 操作 | 预期现象 | 失败判据 |
|---|---|---|---|
| A1 | 启动，等待窗口出现 | 标题为 LWT 语义实验室；无遮挡 | 窗口被其他窗口覆盖 / 无法激活 |
| A2 | 在编辑器输入 `emit 1 + 2;`，点“预测” | 预测区显示 `3`（或等价结果） | 无响应 / 预测报错 |
| A3 | 点“运行” | 输出区显示 `3`，退出码/状态成功 | 输出不符 / 卡死 |
| A4 | 点“解释” | 显示 AST 或解释文本，含加法节点 | 空白 / 异常堆栈 |
| A5 | 点“重置”，再输入 `emit 1 / 0;` 运行 | 显示可定位的除零错误（RuntimeError，含位置） | 静默失败 / 无位置 |
| A6 | 切换输入法输入中文注释 `// 中文`，再用鼠标点击编辑器与按钮 | 光标/焦点跟随鼠标；输入归属明确；无乱码 | 输入落到其他窗口 / 焦点错乱 |
| A7 | 拖动窗口边缘缩放 | 布局跟随，无控件重叠或截断 | 控件重叠 / 不可读 |

截图：A1、A3、A4、A5、A7 各一张。

## C. LWT Snake（约 6 分钟）

启动：`python -m app.lwt_snake`

| 步骤 | 操作 | 预期现象 | 失败判据 |
|---|---|---|---|
| C1 | 启动后按方向键移动 | 蛇按方向移动，分数/状态更新 | 按键无响应 / 反向自杀 |
| C2 | 吃到食物 | 分数增加，长度增加 | 分数或长度不变 |
| C3 | 开启“自动驾驶/策略”开关（若界面提供） | 蛇按策略移动，界面显示策略状态 | 开关无效果 |

## 登记与判定

- 登记脚本输出 `reports/s48-defense/gui-acceptance.{json,md}`：逐项列出文件名、字节数、SHA-256、时间戳、缺项。
- 状态口径：**REGISTERED n/5** 只表示材料已登记；**PASS 必须由本人确认**并在答辩时口头说明。缺项一律 `NOT_RUN`。
- 若中途出现遮挡/输入不可归因：停止该步骤，记录时间与现象，保留截图；该项记 `BLOCKED`，不写通过。
