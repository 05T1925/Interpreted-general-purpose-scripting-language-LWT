# S18 优化规划：LWT 驱动的交互分析工作台与评分证据闭环

状态：规划已由 S18 阶段分支实施；实施结果见 [S18 工作报告](s18-workbench.md)。等待主窗口审查，S12 保持最后收尾。

## 依据与取舍

课程原文的评分为解释器 20、自动测试 20、性能 10、语言说明与人/AI 指南 20、Agent 用 LWT 编写应用 30。当前仓库已有 246 行有效 LWT 日志分析器、194 个语言黑盒用例、性能原始记录、指南和两个 Tk 程序。S17 主窗口实际操作已确认两款 GUI 的主要路径可用，但日志侦探的大窗口题面与输入区间距偏大，完整报告仍主要以原始文本呈现；Snake 是独立 Python 程序，不能代替 LWT 应用证据。详见 [S17 主窗口复核](s17-main-review.md)。

参考资料提供方法启发，不改变教师要求：[Python Tkinter 官方文档](https://docs.python.org/3/library/tkinter.html)说明事件循环和长任务不能阻塞事件处理；[Crafting Interpreters 的测试说明](https://www.craftinginterpreters.com/chunks-of-bytecode.html)强调通过程序运行和预期输出构建语言测试；[GitHub Actions 矩阵文档](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/run-job-variations)说明可按系统和 Python 版本组合验证；[ICFP 工件评估标准](https://icfp26.sigplan.org/track/icfp-2026-artifact-evaluation)强调可运行、文档、验证证据和可复用性。后两者是工程质量启发，**不是课程评分细则**。

## 优先顺序

1. **P0：突出真正的 LWT 应用。** 在现有日志侦探中增加“分析工作台”视图，保留五题挑战。文件选择、级别/关键词/Top 参数由用户交互产生；数据读取、过滤、计数、排序仍由 `app/log_report.lwt` 经公开 `python -m lwt` CLI 完成。Python 只负责调用、严格解析报告和可视化展示，不重新读取或聚合日志。
2. **P0：可核验的报告契约。** 为固定 CLI 文本格式新增纯 Python 解析模型：总行数、有效/坏行、匹配数、级别计数、模块排行、前三条样例和原始文本。拒绝字段缺失/重复、负数或非法计数、section 顺序错误及明显自相矛盾的数据；保持 `--top 0`、无匹配、空字段等合法情况。现有 S10 CLI 输出和 25 项测试不得被破坏。
3. **P1：真正可演示的交互。** 仪表盘显示四项总览、级别/模块条形图、匹配示例和“查看原始 LWT 报告”。过滤后立刻明确显示查询条件，零结果给出可理解空态；查询中禁用重复触发但窗口不冻结，错误可恢复。收紧日志侦探题面与答题区的过大空白。独立 Snake 保留，界面说明明确它由 Python/Tkinter 实现，避免被误认作第二个 LWT 应用。
4. **P1：证据包。** 增加可复现的较丰富 UTF-8 示例日志和若干真实 CLI/GUI 场景；在阶段报告中写明每项教师要求的文件、命令、可见输出和未验证范围。准备答辩可用的演示顺序与故障后退路，但不制作最终 PPT、不做新克隆或远端发布。
5. **P2：只修实测问题。** S17 尚未完成的 GUI 项逐项验收；有可复现缺陷才改动。性能原始数据不因界面开发而重跑，不以增加测试数量代替覆盖证明。

## 建议完成门槛

- 新视图能从默认样例得到 7 总行、6 有效、1 坏行、6 匹配和 ERROR/INFO/WARN 各 2；过滤 `WARN + retry + top 2` 时匹配 1、`cache|1`；零匹配、空日志、坏路径、含空格/Unicode 路径都可理解且不挂界面。
- 原始报告与可视图数值一致；Python 不读取日志内容，不自算过滤、排序或聚合。真实 CLI 子进程测试覆盖报告解析与参数传递；GUI 状态用无头测试和可归因桌面操作分别验证。
- 既有 194/194 黑盒、243 项基线 unittest、完整性检查、S10 25 项契约、246 行 LWT 统计和 `compileall` 均保留通过。新增测试计数以实际结果为准。保护 S10 并发原始记录、S11 性能 raw/报告；不改 LWT 语言语义。
- 阶段分支从最新已审查本地 `main` 建立，分层提交，报告变更、实测命令与结果、桌面逐项状态、风险和未验证项。执行窗口不合并或推送；主窗口随后审查。
