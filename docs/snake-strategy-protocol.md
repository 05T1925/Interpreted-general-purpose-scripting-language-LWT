# LWT Snake 策略协议 LWA1（S36 编码前冻结）

规则仍由 [game.lwt](../app/lwt_snake/game.lwt) 唯一计算。策略是独立长驻 `sys.executable -u -m lwt app/lwt_snake/strategy.lwt`，Python 仅转发已校验快照、管理进程和绘图。工作目录为仓库根，参数数组、shell=False、同时排空两条输出管道。游戏与策略有不同 PID、各自序号；先取消策略，再结束游戏。EOF 安静 exit 0，不设置 QUIT 命令。

## 帧与校验

LF 分帧，帧内仅 ASCII、无 CR/LF。请求最多 4096 字节，响应最多 128 字节（均不含 LF）。请求恰好九字段：

```text
LWA1|000001|WIDTH|HEIGHT|DIR|FOOD_X|FOOD_Y|BODY_LEN|x,y;x,y;...
```

序号是六位 ASCII 数字，从 000001 连续至 999999。宽 4–24、高 1–18、面积至多 432；其余整数为无前导零的非负 ASCII 十进制数（最多三位）。蛇长 3 至面积减一、坐标唯一、相邻正交连接、食物在棋盘内且不在身体上。DIR 为 U/R/D/L，是引擎报告的**下一步方向（含未消费 TURN）**，不从身体推断替换。只查询 RUNNING 快照；不接收 GUI 任意文本或回放未验证坐标。

正常响应恰好五字段：`LWA1|SSSSSS|MOVE|U/R/D/L|FOOD/SPACE`，或 `LWA1|SSSSSS|NONE|-|TRAPPED`。错误四字段：`LWA1|ERR|SSSSSS|BAD_FRAME/BAD_SEQUENCE/BAD_SNAPSHOT`。无法辨认序号用 000000。任何错误均不消费序号、不改变策略状态；合法请求消费一次。非 ASCII、超长、版本/字段数错误为 BAD_FRAME；序号错误为 BAD_SEQUENCE；快照损坏为 BAD_SNAPSHOT。内部异常不捕获成协议成功，由 LWT stderr 和非零退出暴露。

Python 严格检查响应字节、长度、数量、版本、请求序号、方向/理由配对；不寻路、不重算游戏结果。一次仅一项在途请求，队列容量一；默认响应上限 5 秒，stderr 仅保留最后 8192 字节。额外 stdout、半帧、EOF、坏编码、超时、取消均结束并回收策略进程；不会替换为 Python 方向。重试启动新进程，序号从一开始。旧代结果不得覆盖当前快照。

## 确定性算法

方向顺序 U,R,D,L。排除相对 DIR 直接逆向、越墙、撞非离开尾格；吃食物时尾格保留。对每个合法候选构造本步后身体占用，从新头用有限数组队列 BFS；新头可访问，其他预测身体格阻塞。距离为新头到当前食物的静态距离，可达数包含新头。优先距离可达且空间至少为当前蛇长（或本步直接吃食物）的候选，距离最小优先，再按方向序；否则选择可达数最大者，平局按方向序。无合法候选 NONE。它是单步启发式，不保证最优、未来存活或胜利；合法快照不允许食物在尾格，因此“吃尾格同时增长”只能作为损坏输入拒绝。

## UI 所有权与取消

手动模式使用 S35 GameClock。提示在 RUNNING 时临时停手动时钟，查询不发游戏事务；展示方向文字箭头，不盖住棋盘。快照改变或关闭提示清除提示，重新建立手动 deadline。PAUSED 不发送策略请求（演示先继续再提示）。自动驾驶关闭手动时钟，串行策略→必要 TURN→TICK→新快照，链间至少 140ms、慢响应不追赶。真实 TURN/TICK 全部走原 recorder。

手动转向退出自动并接管；关闭自动重新建立手动时钟。暂停、重置、失焦、终态、保存/载入对话框、复盘、接管、关闭均取消策略、递增代号并清空建议；不自动恢复自动驾驶。失焦仍发送 PAUSE，返回焦点需显式继续。策略失败停止全部定时推进，保留最近确认快照和录制前缀；用户可再次提示/自动或手动转向继续。取消只设事件，工作线程回收进程，Tk 不等待 subprocess。旧线程结束前不得创建下一策略 owner。窗口关闭后不再回调 Tk。
