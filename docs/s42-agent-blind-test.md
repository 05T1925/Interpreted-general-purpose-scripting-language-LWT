1. 开一个全新 Agent 会话，不注入本仓库的会话记忆、阶段报告或任务书，仅提供三份材料：开发指南、并发契约卡（`docs/concurrency.md`）、`lwt-app` Skill。
2. 提示语：「用 LWT 写一个程序：两个生产者任务通过通道发送若干整数，一个消费者任务接收并求和；其中一个生产者用 `attempt/recover` 处理一个模拟失败（例如读一个不存在的路径）；主任务按确定顺序输出总和与错误数。只使用公开 CLI `python -m lwt`，写出 `.lwt` 文件并说明如何运行。」
3. 判分（CLI 自动 + 人工）：
   - 语法/静态检查通过（`--check` 退出 0）；
   - 程序在 `fifo` 下运行退出 0、输出确定（重复 5 次逐字节一致）；
   - 正确演示 `spawn`/`channel`/`send`/`receive`/`join`、`attempt/recover`；
   - 未使用非目标能力（抢占、取消、有界通道、嵌套 Profile 等）；
   - 未把 `yield` 当锁或依赖完成顺序输出。
4. 单样本得 pass@1（一次通过计 1）；若跑 n 个样本、c 个通过，按 `pass@k = 1 - C(n-c,k)/C(n,k)` 计算（任务书给定公式）。
