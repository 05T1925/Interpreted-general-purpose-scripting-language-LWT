## 2. 冻结新证据契约，再编码

在 `docs/s38-policy-proof-contract.md` 定义版本化结果和决策证据，先单独提交。最小证明层级要分开：

- `game_verified`：用全新 LWT 游戏进程逐笔重放原 LWS1 请求/响应，复核分数、阶段和事务。
- `policy_verified`：用**全新长驻 LWT 策略进程**，从每步真实游戏快照重新构造 LWA1 请求，按原查询顺序得到建议，核对记录的方向、原因以及它与随后实际 TURN/TICK 的关系；不是依据策略 ID 或源码哈希直接置 true。
- `failed/incomplete`：策略进程或游戏进程故障时只保证已完成前缀能达到的证明层级，不能把故障局标成完成局。未执行的决策、未显示的推测结果不得虚构。`verified` 一词不得同时模糊表示两种证明。

建议新结果 schema v2，每局另有 `decisions/<strategy>-<seed>.json`，记录每个已完成策略问答的序号、所依据的游戏事务索引、规范化 LWA1 请求与精确响应（或足以逐字重建的等价字段）；结果绑定决策文件的 SHA-256、策略及游戏源码 digest、S35 回放 digest。每局至多 100 TICK，明确文件/帧/整数/列表大小上限和固定相对路径，原子写入，不覆盖已有目录。若策略源码未来可 import 模块，必须把依赖闭包纳入 digest 或明确本版仅支持现有两份独立策略。

**历史兼容：**保留 `reports/s37-demo/` 原始 v1 文件及六份回放不变。v1 `--verify` 可继续验证游戏事务，但输出必须明确 `game replay only; strategy decisions unverified`，退出码与文档契约写清；或者以明确迁移命令拒绝 v1 的“完整验真”请求。不可静默把历史 v1 的 `verified=true` 解释为策略证明。新固定样例放 `reports/s38-demo/` 等新目录，给出新 run 身份、源码摘要、命令和结果。SHA-256 是字节完整性标识；重新执行所声明策略可证明当前源码对该输入的确定性一致性，但不能证明历史运行由可信主体产生，勿称“密码学签名”或绝对来源认证。

## 3. 正确的策略链核验

对成功局，从 `INIT → START` 后的真实 RUNNING 快照开始，**每一次** TICK 前恰有一次策略咨询。咨询时使用当时快照；若建议方向与快照方向不同，下一条游戏事务必须是同方向的成功 TURN，随后必须是 TICK；若方向相同，必须直接 TICK。TURN 之后的新快照不能冒充咨询前快照。每次新策略进程产生的 LWA1 响应必须与记录逐字或按冻结的规范化规则一致，包含 `FOOD/SPACE` 原因，不只比较最终分数。终局在 TICK 后结束，不再咨询；`limit` 的咨询次数应等于 TICK 数；`trapped` 要求末快照 RUNNING 并有最后一次 `NONE|-|TRAPPED` 咨询，之后无 TURN/TICK。拒绝多余、缺失、重复、错序决策及非法额外 PAUSE/RESET/手动 TURN。策略进程内部序号必须从 1 连续递增；双进程按当前白名单源码与固定 cwd/输入执行。

对于失败局，逐项定义已完成决策、已发 TURN 但 TICK 失败、已咨询但游戏事务尚未完成、策略超时/坏帧等边界。不要把无法再现的失败原因假装成可重放；只声明游戏前缀及已完成策略问答的可验证程度。任何验证异常须带 `strategy/seed`、第几次决策或第几笔游戏事务、差异字段，非零退出且不打印虚假通过摘要。保持有界超时、stdout/stderr 排空、关闭时进程回收；运行器依旧不在 Python 计算移动合法性、寻路、碰撞、食物或得分。

同时严查 v1/v2 JSON：策略清单和 seed 非空且在原配置范围，至少一个对局，board 面积上限，cases 与笛卡尔积完整对应、顺序与 ID 不可重复；拒绝 bool 伪装整数、负数/超范围、额外或缺失键、重复 JSON key、NaN/Infinity、路径越界、异常大的文件。解析器错误要映射为稳定非零 CLI 诊断，避免 Python traceback。不要为了让错误输入通过而放宽 S35 游戏回放解析器。

## 4. 可解释且可演示的新功能

提供无 GUI 的 `--explain <result.json> --case bfs/4 --step N`（参数形式可按现有 CLI 风格微调）：从已验真的决策证据展示该步的真实棋盘快照摘要、LWT 策略返回的方向/原因、是否发送 TURN、之后的 TICK 结果、分数变化，并指出本步对应的事务和策略源码 digest。展示是证据读取和可视化，不在 Python 重新决策。默认必须先验真；若输入无法验证，不展示“真实策略决策”。输出简单、稳定，适于期末 2–3 分钟演示和无 GUI 后退。可附只读终端棋盘，但不以新 Tk GUI 作为阶段通过门槛。
